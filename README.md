# Практика с персональным ИИ-агентом

Материалы практической части интенсива **«Государство на скорости ИИ»**
(karpov.courses × ВЭБ.РФ, 6–7 августа 2026).

Репозиторий существует ради одного: **передать заготовки в учебных ИИ-агентов участников**.
Участник даёт агенту одну ссылку — и агент ведёт его по одиннадцати шагам, от «вот чем
я занимаюсь» до защищённой заготовки инициативы с расчётом эффекта.

## Точка входа для агента

```
https://raw.githubusercontent.com/wybaeb/veb-ai-practice/main/AGENTS.md
```

Файл читается агентом **без пароля** — иначе он не смог бы его загрузить. Страница
практики для людей закрыта паролем; ссылка для агента лежит внутри неё.

## Страница практики

GitHub Pages — пошаговое описание практики с промптами и примерами, закрыто паролем
(пароль передаётся отдельно, после первого ввода кэшируется в браузере).

## Состав

| Файл | Назначение |
|---|---|
| **`AGENTS.md`** | **Точка входа и полный фреймворк занятия.** Рамка бизнес-инициативы, Шкала автономности L0–L5, коридор достоверности, холст из девяти полей, уровни значимости данных и контуры, правила экономики, границы работы с данными, приоритет инструкций |
| **`PIPELINE.md`** | Одиннадцать шагов: цель → артефакт → что делает агент → полный промпт → критерий готовности |
| **`CHECKLIST.md`** | Definition of Done агента и сценарий приёмки — инженерный документ для того, кто настраивает агента |
| `templates/` | Шаблоны артефактов: паспорт инициативы, холст, заключение о допустимости, финансовая модель, MARP-презентация и тема |
| `icons/` | 36 брендовых иконок (SVG и PNG) для презентаций участников |
| `src/app.html` | Исходник страницы практики (без шифрования) |
| `index.html` | То, что отдаётся на GitHub Pages: парольный гейт + зашифрованный payload |
| `build.py` | Шифрует `src/app.html` паролем (PBKDF2 + AES-256-GCM) и собирает `index.html` |

## Артефакты практики

```
A1  Карта инициатив зоны ответственности
A2  Паспорт инициативы
A3  Обзор реализованных практик
A4  Коридор эффекта
A5  Холст инициативы
A6  Заключение о допустимости
A7  Финансовая модель со сценарным анализом
A8  Презентация инициативы (MARP)
A9  Протокол перекрёстной экспертизы
A10 Дорожная карта на 12 месяцев
```

Каждый следующий артефакт собирается из предыдущих — на защите любая цифра
прослеживается до источника и несёт метку достоверности.

## Пересборка страницы

```bash
python3 build.py --password 'ПАРОЛЬ'
# или
VEB_PRACTICE_PASSWORD='ПАРОЛЬ' python3 build.py
```

Шифрование на стороне сборки (Python `cryptography`) совместимо с расшифровкой
в браузере (WebCrypto): PBKDF2-HMAC-SHA256, 200 000 итераций, AES-256-GCM.

## Финансовая модель

```bash
python3 templates/finmodel.py                 # NPV, сценарии, Монте-Карло, безубыточность
python3 templates/finmodel.py --chart npv.png # плюс гистограмма распределения
```

## Презентация

```bash
npx @marp-team/marp-cli templates/deck_template.md -o deck.pdf --theme templates/theme.css
```

Бренд презентации меняется правкой переменных в `:root` файла `templates/theme.css` —
остальной файл трогать не нужно.

**Правила репозитория** — в [`PUBLIC_ONLY.md`](./PUBLIC_ONLY.md). Репозиторий публичный
и предназначен только для передачи заготовок. Рабочие материалы проекта сюда не попадают;
состав коммитов контролируется хуком `.githooks/pre-commit`.

Все примеры, кейсы и цифры в шаблонах — **учебные и вымышленные**: они показывают формат
работы, а не реальную аналитику.

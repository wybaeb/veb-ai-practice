## Финансовая модель

```bash
python3 finmodel.py                          # отчёт: поток, NPV, сценарии, Монте-Карло, безубыточность
python3 finmodel.py --chart npv_mc.png       # плюс гистограмма распределения NPV
python3 finmodel.py --chart-npv npv.png      # график «когда окупается» для слайда 9
python3 finmodel_xlsx.py -o finmodel.xlsx    # Excel-книга: Константы · Гипотезы · Бенчмарки · Модель · График NPV
```

Правится **только блок ДОПУЩЕНИЯ** в начале `finmodel.py` — остальное считается само;
Excel-книга собирается из тех же допущений, поэтому отчёт и книга не расходятся.
В книге нет ни одного захардкоженного результата — только живые формулы от листа «Константы».
Зависимости: `numpy` обязательно, `matplotlib` только для графиков, `openpyxl` для книги.

В файле лежит учебный вымышленный кейс: все цифры придуманы и служат для проверки,
что расчёт работает.

## Презентация

```bash
python3 check_slides.py deck.md              # проверка вёрстки: заезды на колонтитул
npx @marp-team/marp-cli deck.md -o deck.pdf  --theme theme.css
npx @marp-team/marp-cli deck.md -o deck.html --theme theme.css
```

Тема сама держит типовые проблемы генерации: таблицы принудительно прозрачные,
картинки ограничены по высоте, у слайда безопасная зона над колонтитулом,
KPI-плитки переносятся строками. Что тема удержать не может — лишний объём
текста — ловит `check_slides.py`; чинить сокращением формулировок, не кеглем.

Если `npx` недоступен — MARP открывается расширением Marp for VS Code либо
собирается на стороне среды агента. Участнику достаточно `.md` и `.html`.

### Смена бренда — одна правка

Все цвета и шрифт заданы переменными в `:root` файла `theme.css`. Чтобы перевести
презентации в шаблон организации, меняются значения переменных — остальной файл
не трогается. Сейчас в теме бренд karpov.courses: акцент `#ff5533`, фон `#1e2027`,
шрифт Manrope.

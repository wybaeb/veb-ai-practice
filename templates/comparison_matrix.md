## Правила заполнения

1. **Строки — параметры сравнения**, 6–8 штук, берутся из паспорта инициативы.
   Базовый набор ниже; заменяйте параметры на профильные, если процесс того требует.
2. **Столбцы — сопоставимые организации**, 4–6 штук, плюс обязательный столбец
   **«мы сегодня»**: без него сравнение не с чем соотнести.
3. **В ячейках — факт со ссылкой либо «нет данных».** Правдоподобные значения
   не ставятся. «Нет данных» — нормальный результат исследования.
4. **Последний столбец — вывод по строке:** «минимум» (так делают все — обязательная
   практика) или «отличие» (даёт преимущество). Копировать всё найденное не нужно:
   карго-культ дороже отставания.
5. **Отдельная строка — «как процесс решается сейчас без ИИ»**: руками, силами
   подрядчика, в другом подразделении. Это тоже участник сравнения, и чаще всего
   проигрывает именно он.

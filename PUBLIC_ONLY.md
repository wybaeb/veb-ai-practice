# Разрешённый состав репозитория

Публичный репозиторий существует **только** для передачи заготовок в учебных ИИ-агентов.
Ниже — исчерпывающий список того, что здесь может лежать. Всё остальное — нарушение.

## Белый список путей

| Путь | Что это |
|---|---|
| `AGENTS.md` | Точка входа и полный фреймворк занятия для агента |
| `PIPELINE.md` | Пошаговый пайплайн практики с промптами |
| `CHECKLIST.md` | Definition of Done агента (для разработчика) |
| `README.md` | Описание репозитория |
| `CLAUDE.md`, `PUBLIC_ONLY.md` | Правила публикации |
| `templates/**` | Шаблоны артефактов: MARP-тема и презентация, финмодель, холст, паспорт, заключение |
| `icons/**` | Набор иконок (SVG/PNG) для презентаций участников |
| `src/app.html` | Исходник страницы практики (до шифрования) |
| `index.html` | Собранная страница для GitHub Pages (парольный гейт + шифрованный payload) |
| `build.py` | Сборщик зашифрованной страницы |
| `.githooks/**`, `.gitignore`, `.nojekyll` | Служебное |

## Чёрный список (хук блокирует по содержимому)

- Любой файл вне белого списка.
- Расширения `.docx`, `.pptx`, `.pdf`, `.xlsx`, `.jsonl`, `.bin`.
- Строки-маркеры внутреннего контура: пути `/root/work/veb_gov_ai`, `/root/work/veb-ai-agent`,
  имена приватных репозиториев, `docs.google.com/document`, `ВНУТРЕННЕЕ`, `не для распространения`.
- Признаки секретов: `sk-`, `ghp_`, `AIza`, `BEGIN ... PRIVATE KEY`, `Bearer `, `password=`.

## Как проверить вручную

```bash
.githooks/pre-commit --dry-run
```

Хук возвращает ненулевой код и печатает, какой файл и по какой причине не пропущен.

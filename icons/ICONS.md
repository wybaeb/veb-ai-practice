# Иконки

Брендовый набор интенсива: контурные иконки 24×24, обводка 2 px, без заливки.
Акцентный вариант — `#ff5533`, светлый — `#ffffff` (суффикс `_light`, для тёмного фона).

Форматы: `svg/` — векторные (предпочтительно для MARP и веба), `png/` — 160×160 для вставки в редакторы, не понимающие SVG.

## Как вставить в MARP

```markdown
<img src="icons/svg/target.svg" width="44" alt="">
```

Правило: **не более одной иконки на слайд**. Иконка обозначает тему слайда, а не украшает его.

# ⛔️ ЭТО ПУБЛИЧНЫЙ РЕПОЗИТОРИЙ — ПРОЧТИ ДО ПЕРВОЙ ЗАПИСИ

Репозиторий `wybaeb/veb-ai-practice` **public**. Всё, что попадает сюда, видно всему интернету
и индексируется поисковиками навсегда — даже если потом удалить.

## Назначение — ровно одно

Передача **заготовок для учебных ИИ-агентов** участникам интенсива «Государство на скорости ИИ»:
инструкция агенту, пайплайн практики, шаблоны артефактов, иконки, страница практики.

## Что сюда класть НЕЛЬЗЯ (полный запрет)

- Рабочие файлы проекта: `content.py`, `build_deck.py`, `build_docs.py`, деки `.json`, `.docx`, `.pdf`.
- Программу и расписание интенсива в редакционном виде, служебную переписку, транскрипции встреч.
- Внутреннюю кухню: списки открытых вопросов, договорённости с заказчиком, суммы, ФИО участников,
  оценки и риски, ссылки на приватные Google Docs.
- Реальные материалы ВЭБ.РФ любого рода.
- Любые ключи, токены, пароли, внутренние адреса и hostname.

Рабочие репозитории проекта — `/root/work/veb_gov_ai` и `/root/work/veb-ai-agent`, оба **private**.
Они источник правды. Этот репозиторий — витрина: сюда кладут производные, очищенные от контекста.

## Что класть можно

Только файлы из списка `PUBLIC_ONLY.md`. Он же зашит в `.githooks/pre-commit`:
коммит с файлом вне списка **отклоняется**.

## Проверка перед коммитом

```bash
git config core.hooksPath .githooks   # один раз после клонирования
git add -A && git commit -m "..."     # хук сам проверит состав и содержимое
```

Если хук ругается — не обходи его флагом `--no-verify`. Ругань хука означает,
что ты собрался опубликовать то, что публиковать нельзя.
